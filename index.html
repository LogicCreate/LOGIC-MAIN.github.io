LogicPad

A Windows-native visual programming and AI automation platform designed for clarity, reliability, and control. Build workflows effortlessly with 164 built-in nodes, multi-dimensional arrays, cloud & local LLMs, and a self-contained Python 3.13 runtime.

明快さ・信頼性・高い制御性を備えた Windows ネイティブのビジュアルプログラミング＆AI自動化プラットフォーム。全164種の標準ノード、多次元配列、クラウド／ローカルAI連携、組込 Python 3.13 実行環境をひとつに統合しています。

Key Capabilities 主な機能

Prioritize visual standard nodes for clarity, and drop down into built-in scripting whenever custom algorithms are needed. 見通しの良い標準ノードを中心に構築し、高度な処理が必要な場面では組込スクリプトとも自在に連携できます。

AI Co-Pilot

AI Chat Workflow Builder & Local LLMs AI チャットによる自動構築＆ローカルLLM対応

Generate, explain, and control flowcharts from natural language. Supports OpenAI, Claude, Claude Code CLI, Gemini, DeepSeek, Grok, Perplexity, and local endpoints (Ollama, LM Studio, vLLM).

自然言語の対話からフローチャートの自動生成・解説・実行操作が可能。OpenAI、Claude / Claude Code CLI、Gemini、DeepSeek、Grok、Perplexity に加え、Ollama / LM Studio 等のローカルAIにも対応しています。

164 Nodes

Comprehensive Standard Node Library 全164種の豊富な標準ノード群

Combine ready-made nodes for conditionals, loops, exception handling, math functions, strings, arrays, file/folder operations, timers, clipboard, and Windows desktop control.

条件分岐・反復・例外処理・数学関数・文字列・配列操作・ファイル／フォルダ管理・タイマー・クリップボード・Windows制御など164種の標準ノードを収録しています。

Data & Arrays

N-Dimensional Arrays & Excel-Style Grid 多次元配列変数＆Excelライクなグリッド編集

Create 1D lists, 2D tables, and N-D arrays across all 8 data types (Number, String, Boolean, Date/Time, Color, Image, Binary) with interactive spreadsheet editing, TSV paste, and matrix[r, c] indexing.

数値・文字列・真偽値・日時・色・画像・バイナリの全型で1次元〜多次元配列に対応。スプレッドシート形式のグリッド編集、TSV貼り付け、matrix[r, c] 添字参照を備えています。

Built-In Python 3.13

Self-Contained Python (+ Pillow) & Scripting 組込 Python 3.13（Pillow 同梱）＆多彩なスクリプト

Includes an embedded Python 3.13 runtime with all 20 standard C extensions and Pillow (PIL) bundled out of the box—plus C#, VB.NET, PowerShell, JavaScript, VBScript, and Batch nodes.

標準C拡張一式と画像処理ライブラリ Pillow (PIL) を同梱した Python 3.13 を内蔵し、環境構築不要で即実行可能。C#、VB.NET、PowerShell、JavaScript、バッチ実行にも対応しています。

Web & API

WebView2 Browser & REST API Automation 内蔵 WebView2 ブラウザ＆REST API連携

Automate modern web apps with the built-in Chromium WebView2 browser using XPath clicks, form input, HTML extraction, and screenshots, or connect directly to HTTP REST APIs.

Chromium ベースの WebView2 内蔵ブラウザによる XPath クリック・文字入力・データ抽出・画面キャプチャや、REST API ノードによる外部Webサービス連携を行えます。

Office & Media

Excel COM & Image / QR Processing Excel 自動操作＆画像・QRコード処理

Create Excel workbooks, read/write cells, insert images, and trigger macros. Process images natively with resize, rotation, grayscale, OpenCV template matching, and QR encode/decode nodes.

Excel ブック新規作成・セル読み書き・画像挿入・マクロ実行を自動化。画像リサイズ・回転・グレースケール・OpenCV画像マッチング・QRコード生成／読取ノードも標準搭載しています。

Graph Layout

Smart Topological Layout & Elbow Routing 2D階層自動整列＆障害物回避エルボー矢印

Automatic 2D hierarchical formatting arranges branches and loops cleanly on the grid, with obstacle-aware arrow detours, non-overlapping TRUE/FALSE labels, and port fan-in.

ループや条件分岐を含むフローをグリッド上に美しく配置する2D階層自動整列と、障害物を滑らかに迂回する矢印ルーティングを搭載しています。

Messaging

Email & Team Collaboration Channels メール＆ビジネスチャット通知連携

Deliver automated reports, alerts, and AI summaries directly to Microsoft Teams, Slack, LINE Messaging API, X (Twitter), toast notifications, and SMTP email.

処理結果やAI要約レポートを Microsoft Teams、Slack、LINE Messaging API、X、デスクトップトースト通知、メール送信へそのまま連携できます。

Native UX

Dialog-Style Ergonomics & 97 Languages 快適なキーボード操作＆97言語ネイティブUI

Designed with native Win32 & Direct2D responsiveness: Ctrl+I quick node insertion, Tab/Shift+Tab property navigation, Taskbar Jump List sync, breakpoints, and 97-language UI.

Ctrl+I クイック挿入、プロパティでのラベルクリック＆Tab/Shift+Tab 移動、ブレークポイント・ステップ実行、タスクバージャンプリスト同期、97言語UIを備えています。
